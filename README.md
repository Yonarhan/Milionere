# Milionere

Sistema para produzir **vídeos curtos (YouTube Shorts e TikTok) sem aparecer**, com roteiro, imagens,
narração e legenda sincronizados. Os nichos atuais são **gospel** (fórmula validada) e **curiosidades de astronomia**.

- 🧠 **Fluxo completo e regras de roteiro:** [.claude/skills/roteirista-shorts/SKILL.md](.claude/skills/roteirista-shorts/SKILL.md)
- 🎬 **Roteiros prontos:** [producao/roteiros/](producao/roteiros/)
- 📈 **O que funcionou ou não:** [producao/aprendizados.md](producao/aprendizados.md)
