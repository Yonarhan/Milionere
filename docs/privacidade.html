Política de Privacidade

Última atualização: 24 de setembro de 2026

Milionere é uma ferramenta de uso pessoal do dono do canal Melhor Gospel BR no YouTube.

Que dados acessamos

Com a autorização do dono do canal, a ferramenta usa a API do YouTube (YouTube API Services) apenas para enviar vídeos ao próprio canal, preencher título, descrição e tags, e publicar um comentário nesses vídeos.

O que não fazemos

  • Não coletamos, vendemos nem compartilhamos dados de outras pessoas.
  • Não lemos dados de espectadores, inscritos ou de outros canais.
  • O token de acesso fica guardado apenas no computador do dono do canal.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso da API do YouTube segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.
